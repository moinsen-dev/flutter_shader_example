## Usage Notes

### License Requirements

1. **CC BY-SA 4.0 / 3.0**: Requires attribution and sharing under same license
2. **CC BY 4.0**: Requires attribution only
3. **Public Domain**: No restrictions

### Attribution Format

When using these images, include attribution in this format:
```
Photo: [Author Name] / Wikimedia Commons / [License]
```

### Image URL Patterns

Wikimedia Commons provides images at various resolutions:
- **Thumbnail**: `/thumb/[path]/[width]px-[filename]`
- **Full Resolution**: `/[path]/[filename]`

To change the width, modify the `[width]px` portion of the thumbnail URL.

### Fallback Strategy

If any image becomes unavailable:
1. Visit the source category page
2. Select an alternative image with appropriate licensing
3. Use the same URL pattern to generate the direct image link
